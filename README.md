# Электронный практикум «Информационный менеджмент»

Направление 38.03.05 «Бизнес-информатика», 2026/2027 учебный год.

**Открыть практикум:** https://goxaman2-dot.github.io/im-praktikum-2027/

Рулетка назначает студенту отрасль по ОКВЭД 2 (12 вариантов). Студент выступает руководителем ИТ-службы условной фирмы этой отрасли и выполняет работы на её данных:

| Работа | Содержание | Баллы |
|---|---|---|
| ЛР 1 | Информационные потребности и архитектура прикладных систем | 15 |
| ЛР 2 | Выбор информационной системы по совокупной стоимости владения (TCO) | 15 |
| ЛР 3 | ИТ-сервис, инциденты и соглашение об уровне сервиса (ITIL 4, SLA) | 15 |
| ЛР 4 | Ценность информации для управленческого решения (EMV, EVPI) | 10 |
| ЛР 5 | Портфель проектов информатизации | 15 |
| ЛР 6 | Зрелость управления ИТ по COBIT 2019 | 10 |
| ЛР 7 | Управление данными: аудит качества справочника контрагентов | 10 |
| Тест | Итоговая проверка понимания | 10 |

Работа сохраняется в браузере студента. Кнопка «Сохраниться на данной точке практикума» выдаёт код точки, по которому работу можно продолжить на другом компьютере. Отчёт содержит контрольный код для преподавателя.

Практикум — один файл `index.html` без сборки и внешних зависимостей, кроме шрифтов Google Fonts. Все фирмы и числовые данные условные.
